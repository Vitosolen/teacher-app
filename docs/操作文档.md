# 班级养宠物系统 · 操作文档

> 给**老师（终端用户）**看的使用手册。讲清楚每个功能怎么用、典型课堂场景怎么走。
>
> 部署、启停、排错见 `docs/运维文档.md`；架构、数据模型见 `docs/项目总结.md`。

打开浏览器访问首页（默认 <http://127.0.0.1:5173>），第一次使用先注册一个账号。

---

## 1. 整体导航

登录后顶部 7 个菜单：

| 菜单 | 用途 |
|---|---|
| 📚 **班级** | 班级和学生管理，是其他功能的入口 |
| 📖 **科目** | 维护你教的科目（语文/数学等），用于作业和成绩登记 |
| 📝 **作业** | 布置作业 + 批改 + 订正 |
| 📊 **成绩** | 登记考试 / 测验分数 |
| 📢 **听写** | 单词听写（含 Excel 批量导入 + 浏览器朗读） |
| 🛒 **商城** | 学生用积分给宠物兑换食品/衣服/玩具/家具/房子 |
| ⚙️ **设置** ▾ | 积分规则配置（自定义打分按钮） |

右上角是「欢迎，XX 老师」+ 退出按钮。

## 2. 注册与登录

### 2.1 第一次使用：注册

1. 访问首页自动跳到登录页
2. 切到「**注册**」标签
3. 填写：
   - 用户名（3-50 字符，唯一）
   - 密码（至少 6 位）
   - 显示名（在系统里展示给你看的，比如"张老师"）
4. 点「注册并登录」 → 自动登录跳到班级页

注册时系统会自动给你的账户**配齐 9 条默认积分规则**（回答问题 +1、违纪 -3 等），可在「设置 → 积分规则」修改。

### 2.2 后续登录

直接「登录」标签输用户名密码。Token 默认 7 天有效，过期会自动跳回登录页。

### 2.3 排错

输错密码会有红色横幅明确提示「用户名或密码错误」+ 卡片左右抖动动画。

## 3. 班级管理

### 3.1 新建班级

「📚 班级」页 → 右上角「+ 新建班级」 → 填班名（必填）和年级（可选）→ 创建

### 3.2 编辑 / 删除班级

班级卡片右上角有「编辑」「删除」按钮。**删除会连带删除班内所有学生、宠物、行为、作业**，请慎重。

### 3.3 进班级

点卡片任意区域 → 进入班级详情页（学生表格）。

---

## 4. 学生管理 + 领养宠物

### 4.1 添加学生

班级详情页 → 「+ 添加学生」，两种方式：

- **单个添加**：填姓名（必填）+ 学号（可选）
- **批量粘贴**：每行一个姓名，一次粘贴全班几十人

> 学生添加后**没有宠物**，需要后续主动领养（见 4.3）。

### 4.2 编辑 / 删除学生

学生表格每行右侧有「编辑」「删除」按钮。

### 4.3 领养宠物 🐾

每个学生都需要主动领养一只宠物，宠物才会在场景里出现并参与打分动画。

1. 点学生姓名进入学生详情页
2. 没有宠物时显示大按钮「🐾 立即领养」
3. 在弹窗中**选物种**（6 选 1）：

| 物种 | 蛋 → 幼 → 少 → 成 |
|---|---|
| 小龙 | 🥚 → 🦎 → 🐉 → 🐲 |
| 小猫 | 🥚 → 🐈 → 🐱 → 😺 |
| 小狗 | 🥚 → 🐕 → 🐶 → 🦮 |
| 小兔 | 🥚 → 🐰 → 🐇 → 🐰 |
| 熊猫 | 🥚 → 🐼 |
| 狐狸 | 🥚 → 🦊 |

4. 给宠物**起名**（如"小白"、"贝贝"）
5. 点「领养」 → 学生从此拥有这只宠物，等级 1 级，初始心情 80、饥饿 60

每个学生**只能有一只宠物**，领养后无法换物种。

## 5. 打分（系统的核心日常）

### 5.1 在班级页快速打分

班级详情页学生表格每行有：

- 「**+ 加分**」绿色按钮 → 弹窗显示所有奖励规则按钮
- 「**- 减分**」红色按钮 → 弹窗显示所有提醒规则按钮

点击规则按钮立即应用并关闭弹窗。学生表格的心情条/饥饿条/积分会实时更新。

升级时右上角弹横幅：「🎉 XX 的宠物升级了！」

### 5.2 在学生详情页打分

进入学生详情 → 中间「快捷打分」区域：

- 上半部「👍 奖励」：所有正向规则按钮
- 下半部「⚠️ 提醒」：所有负向规则按钮 + 「自定义...」

**自定义打分**：点「自定义...」打开弹窗，可填 -100 到 +100 任意整数 + 类别 + 原因。适合考试 90+ 一次给 +20 这种重大事件。

### 5.3 自定义积分规则

如果默认 9 条不够用（比如你想加「考试 90 以上 +5」），去「⚙️ 设置 → 积分规则」：

- 顶部分两组：👍 奖励规则 / ⚠️ 提醒规则
- 「+ 新建规则」配置：名称 / 类别 / 分数（-100 ~ +100）/ 排序 / 是否启用
- 已有规则可编辑、停用（开关）、删除
- 修改即时生效到所有打分面板

### 5.4 打分对宠物的影响

| 类型 | 经验 | 心情 | 饥饿 | 积分余额 |
|---|---|---|---|---|
| 加分（>0） | `+score×10` | `+score×5`，封顶 100 | `+score×3`，封顶 100 | **`+score`** |
| 减分（<0） | 不变 | `+score×5`，保底 0 | `+score×2`，保底 0 | **不扣** |

**升级**：经验 ≥ `等级×100` 时升级，可一次连升多级。

**懒衰减**：每 24 小时心情和饥饿各 -5（系统自动算，无需操作）。

### 5.5 撤销 / 编辑打分

进学生详情页 → 右侧「行为记录」时间线，每条记录鼠标悬停可见：

- ✏️ **编辑**：改类别和原因（不改分数，避免回滚复杂副作用）
- 🗑️ **删除**：撤销这条记录。如果原本是加分，会**从积分余额扣回**（保底 0）；宠物经验、心情、饥饿不会回滚（因为可能已经发生了衰减或升级）

## 6. 作业管理 + 订正

### 6.1 创建作业

「📝 作业」页 → 「+ 创建作业」：
- 选**班级**和**科目**（科目要先在「📖 科目」页建好）
- 填**标题**（如"作文 500 字"）
- 填**内容**（题目说明，可选）
- 选**截止日期**（可选）
- 提交后系统**自动为班内每个学生生成一条作业记录**

### 6.2 批改作业

作业卡片点进去 → 学生表格逐行：
- 输入分数（0-100）
- 写评语（最多 500 字）
- 点「保存」 → 状态从「未提交」变「已批改」

### 6.3 订正机制（自动判定）⚠️

批改时如果**分数 < 90**（A 等阈值），系统自动标记需要订正：

| 状态徽章 | 含义 |
|---|---|
| ✓ **已订正** | 老师已确认订正完成 |
| ⚠ **待订正（今日）** | 同日批改的，还在订正期内 |
| 🚨 **逾期未订正** | 跨日还没订正，警示 |

老师点「**标记已订正**」按钮 → 状态转 ✓。如果搞错也可以「撤销」回去。

> **重要**：如果给学生**重新批改**（比如原 60 改成 80），「已订正」状态会自动重置 — 因为重新打分意味着原来的订正可能不算数了，要求再次确认。

### 6.4 作业列表的待订正提醒

作业卡片底部如果还有学生没订正，会显示「⚠️ X 名学生待订正」橙色提示，方便老师巡检。

## 7. 成绩登记（考试 / 测验）

跟作业用一套表格，但**不需要订正**。

「📊 成绩」页 → 「+ 登记成绩」：
- 选班级 + 科目
- 填**名称**（如"2025 期中考"、"第 3 单元测验"）
- 填备注（可选，如"满分 100，含选择题与作文"）

进入详情页录入每个学生的分数 + 备注。

**与作业的区别**：
- 没有截止日期
- 没有订正栏
- 列表卡片标题是「登记进度」而非「批改进度」

## 8. 单词听写

### 8.1 维护词库

「📢 听写」页 → 「+ 新建词库」：
- 名称（如"五年级上册 Unit 3"）
- 朗读语言（英语美式/英式、中文、日语、法语、德语 6 选 1）
- 排序、说明

### 8.2 录入单词

点词库卡片进入详情 → 「+ 添加单词」，三种方式：

- **单条添加**：单词 + 释义
- **批量粘贴**：每行一条，支持以下格式
  ```
  apple 苹果
  banana,香蕉
  cat\t猫
  dog
  ```
- **📊 Excel 导入**：上传 .xlsx
  - 第 1 列：单词
  - 第 2 列：释义（可选）
  - 含表头会自动跳过（识别"单词/word/词汇"等关键词）
  - 上传后预览前 10 行 + 总数 → 确认导入

### 8.3 开始听写 📢

词库详情页 → 「📢 开始听写」 → 配置：
- **抽取数量**：从词库中抽几个（默认全部）
- **每词朗读遍数**（默认 2 遍）
- **词间间隔**（让学生写的秒数，默认 5 秒）
- **朗读语速**（0.5x ~ 1.5x）
- **是否随机打乱**（默认是）

点「▶ 开始听写」：
1. 大屏显示当前题号 / 总数 + 「🔊」动画
2. 自动朗读单词，按设定遍数重复
3. 每题之间倒计时显示剩余秒数（让学生写）
4. 全部播完后**展示答案列表**，可切换隐藏/显示拼写让学生对答案
5. 中途可随时点「⏹ 停止」或「🔁 再读一遍」

> **要求**：浏览器需要支持 `SpeechSynthesis`（Chrome / Edge 完美支持）。

## 9. 积分商城 🛒

### 9.1 商品分类（5 类共 20 件预置）

| 类别 | 件数 | 用途 | 装备规则 |
|---|---|---|---|
| 🍽️ **食品** | 4 | 提升宠物饥饿度 / 心情 | 消耗品（用完没了） |
| 👗 **衣服** | 5 | 给宠物穿戴 | 同时**只能穿 1 件** |
| 🎮 **玩具** | 3 | 提升宠物心情 | 消耗品 |
| 🏠 **房子** | 3 | 给宠物一个家 | 同时**只能住 1 个** |
| 🛋️ **家具** | 5 | 装饰房间 | **可同时摆多件** |

价格从 10 积分（苹果）到 1500 积分（梦幻城堡）不等。

### 9.2 兑换流程

「🛒 商城」页：
1. 顶部选**班级**和**学生**（学生选项里显示当前积分余额 💰）
2. 切换商品分类标签
3. 点商品卡片下方「兑换」按钮 → 二次确认 → 扣积分 + 入库到该学生宠物

> 积分不够时按钮置灰，提示具体差多少。

## 10. 宠物世界（学生详情页顶部场景）

进入学生详情页，最显眼的就是**宠物场景**：

### 10.1 没领养宠物

显示「🐾 还没有宠物」+ 立即领养按钮。

### 10.2 没买房子（领养了但流浪）

显示宠物 emoji + 「🥺 还没有自己的家，快去商城买一座房子吧」提示。

### 10.3 已入住房子（完整场景）

```
☀️  ☁️ ☁️                   [Lv  心情  饥饿  活动]
       ╱╲
      ╱  ╲ 🏠 温馨小屋          ← 房子名
     ╱____╲
   ┌─────────────┐
   │ 🪟  🖼️  🪟 │              ← 后墙：窗户 + 画作
   ├─────────────┤
   │ 🛏️ 🐉💤 🛋️ │              ← 屋内：床 + 宠物 + 沙发
   │ 🪴      🪑 │              ← 角落：盆栽 + 椅子
   │    小白     │
   └─────────────┘
🌱🌱🌱🌱🌱🌱🌱🌱🌱🌱
```

**家具按 emoji 自动放固定位置**：床→左侧、沙发→右侧、椅子→右下、盆栽→左下、画作→后墙正中。

### 10.4 宠物 4 种活动状态（自动循环）

| 活动 | 视觉 | 触发 |
|---|---|---|
| 😊 站立 | 上下浮动 | 默认 |
| 💤 睡觉 | 倾斜 + 💤 浮动 | 饥饿 ≤ 30 + 有床 / 自动循环 |
| 🍽️ 吃饭 | 旁边出现 🥣 | 自动循环 |
| 🎉 玩耍 | 左右摇摆 + 🎉 | 心情 ≤ 40 + 有家具 / 自动循环 |

每 6 秒切换一次状态，让宠物看上去"在生活"。

### 10.5 物品栏操作（场景下方）

「物品栏」面板按 5 类分组展示已购物品，点按钮：

- 🛏️ 房子 → 「入住」/「收起」
- 🛋️ 家具 → 「摆放」/「收起」
- 👗 衣服 → 「装备」/「卸下」（穿在宠物身上左上角显示）
- 🍽️ 食品 → 「喂食」（提升饥饿值，物品消耗）
- 🎮 玩具 → 「玩耍」（提升心情，物品消耗）

## 11. 随机点名 🎲

班级详情页右上角「🎲 随机点名」按钮：

1. 输入抽取人数（1 ~ 班级人数）
2. 点「开始抽取」
3. 转盘动画快速切换学生姓名 → 缓停
4. 抽中的学生以卡片形式弹出（带 emoji + 学号）

适合：上课提问、抽查作业、随机分组。

## 12. 课堂典型用法（一节课怎么走）

> 下面是建议流程，你可以挑用。

| 时间 | 动作 | 操作位置 |
|---|---|---|
| 课前 5 分钟 | 检查上节课作业订正情况 | 📝 作业 → 看是否有 ⚠️ 待订正 |
| 上课 0-5 分钟 | 🎲 随机点名抽 3 人朗读课文 | 班级详情页 |
| 课中提问环节 | 「+ 加分」→ 回答问题 +1 | 班级详情页学生表 |
| 不守纪律时 | 「- 减分」→ 违纪 -3 | 班级详情页 |
| 听写小测 | 「📢 听写」→ 选今日词库 → 开始 | 听写页 |
| 课后 | 给重大事件自定义大额加分（例如全员表现好 +5） | 学生详情页「自定义...」 |
| 周末 | 检查商城兑换情况 / 引导学生攒积分 | 🛒 商城 |
| 月末 | 「📊 成绩」登记月考分数 | 成绩页 |

## 13. 业务规则速查（贴墙看）

```
打分对宠物：
  正分：经验 +score×10、心情 +score×5、饥饿 +score×3，并累加积分余额
  负分：心情 +score×5、饥饿 +score×2，不扣经验、不扣积分

升级：经验达到 等级×100 即升级
衰减：每 24 小时心情、饥饿各自然 -5

派生状态：
  健康：心情>30 且 饥饿>30
  饥饿：饥饿≤30
  难过：心情≤30
  虚弱：心情≤10 或 饥饿≤10

订正阈值：作业批改分数 < 90 自动标记待订正
重新批改：清空"已订正"状态，要求再次确认
考试不触发订正

物品装备：
  衣服 / 房子：同时只能 1 件，新装备替换旧的
  家具：可同时摆多件
  食品 / 玩具：吃完用完就没了
```

## 14. 上手有问题？

- 页面**完全空白 / 无数据**：屏幕顶部应该会出现红色横幅提示「无法连接后端服务」+ 排错指引；按指引检查后端是否启动
- 操作**没反应**：F12 打开浏览器开发者工具看 Console / Network 有没有报错
- 数据**乱了 / 想重来**：见 `docs/运维文档.md` §6.3 数据库重置
- 部署 / 启停问题：见 `docs/运维文档.md`
